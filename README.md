# WebRover 🕷️

WebRover is a fast, extensible web scraper and crawler built to discover, crawl, and extract structured data from websites.

> Explore the web. Collect the data. Keep control.

## ✨ Features

- 🕷️ **Web Crawling**  
  Discover and traverse pages starting from one or more seed URLs.

- 🔍 **Web Scraping**  
  Extract structured data from HTML pages using configurable selectors.

- ⚡ **Concurrent Crawling**  
  Crawl multiple pages concurrently for improved performance.

- 🎯 **URL Filtering**  
  Control which URLs WebRover should crawl using domains, patterns, and rules.

- 🚦 **Rate Limiting**  
  Respect target servers with configurable request delays and concurrency limits.

- 🔄 **Retry Handling**  
  Automatically retry failed requests with configurable backoff strategies.
